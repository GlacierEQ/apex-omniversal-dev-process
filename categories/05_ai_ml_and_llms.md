# 🧠 CATEGORY 05: Artificial Intelligence, LLMs & Machine Learning

## 1. Scope & Architectural Mandate
Governs high-throughput AI pipelines, large language model orchestrations, neural architectures, embedding indexing, Model Context Protocol (MCP) servers, and hardware acceleration on GPUs/NPUs.

- **Domains**: Transformer optimizations (Multi-Head Latent Attention - MLA, FlashAttention-3), KV cache management, quantized inference (FP8, INT4, Apple ANE), semantic vector search (HNSW, cosine similarity), fine-tuning (LoRA, QLoRA), MCP tool dispatchers.
- **Key Constraints**: Bounded Time-To-First-Token (TTFT $< 50\text{ms}$ on fast lanes), zero unhandled context window overflows, deterministic tool schemas, strict guardrails against prompt injection.

## 2. Polyglot Technology Stack
- **Languages**: Python (default for AI research & pipelines), C++ / CUDA (kernel optimizations), Swift / Metal (Apple Silicon ANE/GPU acceleration), MLIR (tensor compiler).
- **Frameworks**: PyTorch, Hugging Face `transformers`, vLLM, Ollama, ONNX Runtime.
- **Protocols & Standards**: Model Context Protocol (MCP JSON-RPC 2.0), OpenAI API format, Anthropic Messages API.

---

## 3. Core Invariants & Fail-Closed Boundaries
1. **Context Window Boundary Invariant**:
   - Token budgets must be pre-calculated before dispatch.
   - Incoming payloads that exceed token capacity must be summarized or truncated with explicit notification—never silently dropped or causing API HTTP 400 crashes.
2. **Schema & Tool Execution**:
   - All tool calls dispatched by an LLM must be strictly validated against JSON schema before execution. Hallucinated arguments must trigger structured repair loops, not system panics.
3. **Refusal Reason Codes**:
   - `ERR_AI_CONTEXT_LIMIT_EXCEEDED`: Prompt length exceeds model context window.
   - `ERR_AI_TOOL_SCHEMA_VIOLATION`: Arguments generated by LLM failed JSON schema validation.
   - `ERR_AI_HALLUCINATION_DETECTED`: Output failed ground truth or invariant assertion check.
   - `ERR_AI_SAFETY_VIOLATION`: Adversarial prompt injection or prohibited safety trigger detected.
   - `ERR_AI_INFERENCE_TIMEOUT`: Provider failed to stream response within SLA threshold.

## 4. Stage-by-Stage Implementation Guide

### Stage 0: Contracting
- Specify model family, quantization tier, parameter scale (e.g., 7B, 14B, 70B, MoE), context limit, and latency requirements.
- Define evaluation benchmark datasets and acceptable accuracy thresholds.

### Stage 1: Architectural Modeling
- Define tool registry schemas with JSON Schema Draft 2020-12.
- Design multi-model routing tier (e.g., fast flash router $\to$ deep reasoning agent $\to$ perception specialist).

### Stage 2: Pro-Code Implementation
- Implement streaming token processors with SSE (Server-Sent Events) backpressure.
- Integrate KV cache quantization and memory eviction policies.

### Stage 3: Adversarial Verification
- Run adversarial prompt injection suites (jailbreaks, prompt leaks, hidden instruction hijacking).
- Test with empty prompts, extremely large payloads (1M+ tokens), and invalid tool arguments.

## 5. Reference Pattern: Fail-Closed MCP Tool Invoker
```python
from typing import Dict, Any, Callable
import json
import jsonschema

class MCPToolRegistry:
    def __init__(self):
        self.tools: Dict[str, Dict[str, Any]] = {}

    def register_tool(self, name: str, schema: dict, handler: Callable):
        self.tools[name] = {"schema": schema, "handler": handler}

    def execute_tool(self, tool_name: str, raw_arguments: dict) -> Dict[str, Any]:
        # Tool existence check
        if tool_name not in self.tools:
            return {
                "success": False,
                "code": "ERR_AI_TOOL_NOT_FOUND",
                "message": f"Tool '{tool_name}' is not registered in the catalog"
            }

        tool = self.tools[tool_name]
        # Fail-closed schema validation
        try:
            jsonschema.validate(instance=raw_arguments, schema=tool["schema"])
        except jsonschema.ValidationError as err:
            return {
                "success": False,
                "code": "ERR_AI_TOOL_SCHEMA_VIOLATION",
                "message": f"Schema mismatch: {err.message}",
                "path": list(err.path)
            }

        # Safe execution
        try:
            result = tool["handler"](**raw_arguments)
            return {"success": True, "code": "SUCCESS", "output": result}
        except Exception as e:
            return {
                "success": False,
                "code": "ERR_AI_TOOL_EXECUTION_FAILURE",
                "message": str(e)
            }
```
